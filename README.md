Palmshade Heat is an original open-world crime game that runs entirely in the browser. Explore a coastal city on foot or by car, weave through traffic and pedestrians, steal and drive cars, take on story missions, fight, and outrun the police as your wanted level rises — with a full HUD, minimap, start screen, and save game. No build step and no network needed: just static files in `game/`.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in desktop Chrome
```
